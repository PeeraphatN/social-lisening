## สิ่งที่ตรวจ

1. ข้อความตรงกับข้อมูลอ้างอิงที่ผู้ใช้ยืนยัน หลังปรับเฉพาะช่องว่าง/บรรทัดใหม่ ไม่ตัดหรือแทน emoji
2. บันทึก SHA-256 ของข้อความดิบ เพื่อแยกการเปลี่ยนแปลงด้านช่องว่างออกจากการเปลี่ยนเนื้อหา
3. ตรวจว่าชื่อผู้เขียนที่รู้จากข้อมูลอ้างอิงปรากฏในส่วนหัวของหน้า ไม่อ้างว่าเป็นตัวดึงชื่อทั่วไป
4. เก็บผลล้มเหลวแยก ไม่ตัดตัวอย่างที่ดึงไม่ได้ออกจากตัวหาร 5 โพสต์
5. รวมผลที่ตรงข้อมูลอ้างอิงเป็นไฟล์โพสต์ไม่ซ้ำ โดยคงเวลาเก็บและรอบที่ดึงได้ล่าสุด

## ขอบเขตผลทดลอง

P01–P04 ใช้ URL ที่ผู้ใช้ให้มา ส่วน P05 ใช้ URL เจาะจงโพสต์ในกลุ่มสาธารณะ จาก group ID/post ID เดิมที่อยู่ในลิงก์ผู้ใช้ คำอธิบายกลุ่มไม่ได้ถูกนำมาใช้เป็นข้อความโพสต์

เกณฑ์นี้ทดสอบการดึงข้อความจากลิงก์ที่ทราบแล้วและการยืนยันชื่อผู้เขียนที่รู้ล่วงหน้า ไม่ทดสอบการค้นหาโพสต์ทั่ว Facebook การดึงชื่อผู้เขียนทั่วไป เวลาตีพิมพ์ที่แน่นอน หรือข้อมูลความคิดเห็น

ตัวอย่างจริงของ P04 มี URL ในข้อความและรูป ไม่มีกล่อง link preview ข่าวที่ยืนยันได้ จึงยังไม่สรุปว่าตัวดึงแยกพาดหัวใน link preview ได้ทุกกรณี ข้อมูลเป็นตัวควบคุมทางเทคนิค ไม่ใช่ชุด sentiment ของ TKC

## ไฟล์ผลลัพธ์

- `summary.json`: สถานะและผลแต่ละรอบ พร้อมเวลา UTC
- `checks.csv`: ผลตรวจแต่ละโพสต์ในแต่ละรอบ
- `posts.csv`: ผลข้อความล่าสุดที่ตรงข้อมูลอ้างอิง หนึ่งรายการต่อหนึ่งตัวอย่าง
- `references.json`: สำเนาข้อมูลอ้างอิงที่ตรวจ hash แล้วก่อนเริ่ม

ภาพหน้าจอ ข้อความ และ JSON ของแต่ละรอบอยู่ใน `experiments/facebook_posts/runs/` โดยชื่อขึ้นต้นด้วย session ID เดียวกัน

ตัวรันจบแล้ว `summary.json` ระบุ `status=complete`, `passed=true` ตรวจไฟล์ CSV กลับแล้วพบผลตรวจ 15 รายการ ทุกสถานะเป็น match และไฟล์รวมมี 5 รายการไม่ซ้ำ ข้อความทุกแถวตรง hash ของข้อมูลอ้างอิงและมาจากรอบ 3

ตรวจโปรแกรมแบบ offline: 9 tests ผ่าน ครอบคลุมการไม่ถือ preview เป็นข้อความเต็ม ข้อความกำกวม การเปลี่ยน emoji ชื่อผู้เขียนที่ยืนยันไม่ได้ URL ที่ไม่อนุญาต และ HTTP 429 การตรวจไฟล์ผลหลังรันเป็นการตรวจชุดข้อมูลจริงเพิ่มจาก unit tests

**ข้อสรุปที่ใช้ได้:** ตัวทดลองดึงข้อความจากลิงก์สาธารณะทั้ง 5 รูปแบบนี้ได้ซ้ำ 3 รอบในช่วงเวลาประมาณ 21 นาที โดยข้อความไม่เปลี่ยนและไม่ต้องล็อกอิน ผลนี้ยังไม่รับประกันการทำงานตลอดวัน การค้นพบโพสต์ใหม่ หรือการรองรับ Facebook ทุกประเภทโพสต์
