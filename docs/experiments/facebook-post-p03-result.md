# ผลทดลอง P03: โพสต์พร้อมรูปและข้อความสั้น

วันที่ทดลอง: 7 ตุลาคม 2026

ลิงก์จากผู้ใช้: https://www.facebook.com/armymidecal/posts/pfbid0JxWfJCYeusVdhSEwNVrfYPdVsoEvFQNDYa4ndMkcNi2ALTT3NHuNMno4fkkzrYu5l

สถานะ: **P03 ผ่านการตรวจเทียบข้อความโดยผู้ใช้** ผู้ใช้ยืนยันว่า “ข้อความถูกต้องครับ” เมื่อ 7 ตุลาคม 2026 ตามเวลาไทย ตอนนี้ยืนยันแล้ว 3 จาก 5 โพสต์ ยังไม่ได้รันชุดทดลองครบ 3 รอบ

| รายการ | ผล |
| --- | --- |
| วิธี | Playwright/Chromium ไม่ล็อกอิน HTTP 200 ไม่มีค่า API หรือบริการ scraping |
| ผู้เผยแพร่ | หน่อย โซ่ตึง ชื่อจาก metadata ตรงกับชื่อในภาพหน้าจอ |
| ข้อความ | 143 อักขระ เป็นข้อความสั้นประกอบรูปเกี่ยวกับงานออกแบบ 3D |
| การเทียบ DOM | พบข้อความหนึ่งรายการ ปรับเฉพาะช่องว่างและบรรทัดใหม่แล้วตรงกับ embedded JSON |
| เวลาบนหน้า | “หนึ่งวันที่แล้ว”; ยังเก็บ `published_at=null` เพราะไม่ยืนยันเวลาตีพิมพ์แน่นอน |

ผลดิบยังใช้ `status=candidate_text_unverified`, `manual_match=null` ตามเดิม หลังผู้ใช้ตรวจเทียบและยืนยันข้อความแล้ว บันทึกผลแยกใน `p03-verified.json` และ `p03-verified.csv` เป็น `status=ok`, `manual_match=true` พร้อมข้อความยืนยัน เวลา UTC และ SHA-256 ของข้อความที่ตรวจ

เก็บข้อความ 143 อักขระใน `p03-reference.json` เป็นข้อมูลอ้างอิงสำหรับการดึงรอบถัดไป การยืนยันใช้กับข้อความครั้งนี้เท่านั้น ไม่ถือว่าการดึงใหม่ผ่านอัตโนมัติ

ภาพหน้าจอแสดงรูปและข้อความหลังกล่องชวนล็อกอิน ตัวทดลองไม่ได้ล็อกอินหรือปิดกล่องนั้น เก็บเฉพาะข้อความโพสต์ในไฟล์ส่งออก ไม่อ่านคำจากรูปด้วย OCR ตัวอย่างนี้เป็นตัวควบคุมทางเทคนิค ไม่ใช่ความคิดเห็นเกี่ยวกับ TKC

ไฟล์ใน `experiments/facebook_posts/runs/`:

- `p03-post.txt`: ข้อความสำหรับตรวจ
- `p03-verified.csv`, `p03-verified.json` และ `p03-reference.json`: ผลที่ตรวจผ่านและข้อมูลอ้างอิง
- `p03-post.csv` และ `p03-post.json`: ข้อความและข้อมูลต้นทาง
- `p03-browser-01.png`: ภาพหลักฐาน
- `p03-browser-01-inspection.json`: ผลตรวจจากเบราว์เซอร์

CSV เป็น UTF-8 with BOM ตรวจเปิดกลับแล้วมี 1 รายการและข้อความตรงกับ JSON
