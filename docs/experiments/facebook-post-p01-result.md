วันที่ทดลอง: 7 ตุลาคม 2026

ลิงก์จากผู้ใช้: https://www.facebook.com/share/p/19TTvcsmZ8/

สถานะ: **P01 ผ่านการตรวจเทียบโดยผู้ใช้** ผู้ใช้ยืนยันว่า “ตรวจสอบดูแล้วตรงกันครับ ผ่าน” เมื่อ 7 ตุลาคม 2026 ตามเวลาไทย ยืนยันแล้ว 1 จาก 5 โพสต์ ยังไม่ได้รันชุดทดลองครบ 3 รอบ

## ผลที่พบ

| วิธี | ผล |
| --- | --- |
| web reader | Cache miss ไม่สามารถอ่านเนื้อหาได้ ไม่ใช่หลักฐานว่า Facebook ปิดกั้นโพสต์ |

## หลักฐานและความครบถ้วน

ภาพหน้าจอแสดงโพสต์อยู่หลังกล่องชวนล็อกอินที่มีปุ่มปิด ตัวทดลองไม่ได้ล็อกอิน ไม่กรอกรหัสผ่าน และไม่ได้คลิกปิดกล่องนั้น

เทียบข้อความ embedded JSON กับข้อความใน DOM หลังปรับเฉพาะช่องว่างแล้ว ต่างกันเพียง ` :)` ตอนท้าย ซึ่งหน้าแสดงเป็นภาพอารมณ์แทนข้อความ ไม่ได้ตัดหรือแก้ข้อความต้นฉบับในไฟล์ส่งออก

ผลดิบตอนดึงคง `status=candidate_text_unverified` และ `manual_match=null` ไว้ตามเดิม หลังผู้ใช้ตรวจเทียบแล้ว ได้บันทึกผลแยกใน `p01-verified.json` และ `p01-verified.csv` เป็น `status=ok`, `manual_match=true` พร้อมข้อความยืนยัน เวลา UTC และ SHA-256 ของข้อความที่ตรวจแล้ว

เก็บ `p01-reference.json` เป็นข้อมูลอ้างอิงสำหรับเปรียบเทียบการดึงครั้งถัดไป การยืนยันนี้ใช้กับข้อความ P01 ที่เก็บครั้งนี้เท่านั้น ไม่ถือว่าข้อความจากการดึงครั้งใหม่ผ่านโดยอัตโนมัติ

## ไฟล์ผลลัพธ์ในเครื่อง

อยู่ใน `experiments/facebook_posts/runs/`:

- `p01-post.txt`: ข้อความที่เก็บได้สำหรับตรวจด้วยมือ
- `p01-verified.csv`, `p01-verified.json` และ `p01-reference.json`: ผลที่ผู้ใช้ตรวจผ่านและข้อมูลอ้างอิง
- `p01-post.csv` และ `p01-post.json`: ผลก่อนการตรวจเทียบ เก็บไว้เพื่อย้อนตรวจ
- `p01-browser.png`: ภาพหน้าจอหลักฐาน
- `p01-browser-inspection.json`: ข้อมูลตรวจ DOM กับข้อความจากหน้า
- `p01-http-01.json` และ `p01-http-02.json`: ผลการตรวจ HTTP

CSV ใช้ UTF-8 with BOM และตรวจแล้วว่าเปิดกลับมาได้ 1 รายการ โดยข้อความตรงกับ JSON

ไฟล์ผลจริง, browser binaries, virtual environment และ session data ถูกกันจาก Git ด้วย `.gitignore` เฉพาะโฟลเดอร์ทดลอง ไม่มีค่า API หรือบริการภายนอกสำหรับการดึงรอบนี้

## วิธีรันตัวทดลองซ้ำ

จาก root ของ workspace ใน PowerShell:

```powershell
.\experiments\facebook_posts\.venv\Scripts\python.exe experiments/facebook_posts/inspect_browser.py https://www.facebook.com/share/p/19TTvcsmZ8/ --run-id p01-browser-02
```

นี่เป็นตัวทดลองหนึ่งลิงก์ มี selector เฉพาะ DOM ที่พบในรอบนี้ ยังไม่ใช่ collector พร้อมใช้งานต่อเนื่องทุกประเภทโพสต์ หากเครือข่ายถูก sandbox จำกัดต้องอนุญาตการเชื่อมต่อก่อน

ตรวจ parser แบบ offline:

```powershell
python -m unittest discover -s experiments/facebook_posts -p test_probe_post.py
```

ผลตรวจ: 4 tests ผ่าน ครอบคลุมการไม่ถือ preview เป็นข้อความเต็ม, เก็บภาษาไทย/emoji, ไม่เลือกข้อความเมื่อกำกวม และไม่รับ URL ที่มี credentials หรืออยู่นอก Facebook

ข้อจำกัด: มีข้อมูลอ้างอิงที่ผู้ใช้ตรวจแล้วสำหรับ P01 เท่านั้น ยังไม่ยืนยันเวลาตีพิมพ์ ยังไม่ได้ดึงความคิดเห็น/ข้อความในรูป และยังไม่ทดสอบการค้นพบโพสต์จาก keyword

ขั้นต่อไป: เตรียม P02 ซึ่งเป็นโพสต์ข้อความยาวที่ต้องกด “ดูเพิ่มเติม” เพื่อทดสอบว่าดึงข้อความครบได้อีกครั้ง
