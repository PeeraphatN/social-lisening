โพสต์เกี่ยวกับแหล่งฝึกทักษะ Quant มีรูปประกอบและลิงก์ในข้อความ ใช้เป็นตัวควบคุมทางเทคนิค ไม่ใช่ความคิดเห็นเกี่ยวกับ TKC และไม่ใช่ตัวอย่างข่าวที่ยืนยันว่ามีพาดหัวในกล่อง link preview กรณีแยกพาดหัวข่าวออกจากข้อความผู้โพสต์จึงยังไม่ถูกทดสอบ

## การตรวจข้อความ

พบข้อความโพสต์ใน DOM หนึ่งรายการ เมื่อเทียบหลังปรับเฉพาะช่องว่าง พบว่าหน้าแสดง URL ยาว 3 จุดแบบย่อด้วย `...` และ emoji 2 จุดเป็นภาพแทนข้อความ จึงไม่ถือว่า DOM text ตรงกับ JSON แบบตัวอักษรต่อตัวอักษร

ไฟล์ส่งออกคงข้อความจาก embedded JSON ตามต้นทาง รวม URL และ emoji ไม่แก้ข้อความให้ตรงกับการแสดงแบบย่อใน DOM ผลดิบคง `status=candidate_text_unverified`, `manual_match=null` ตามเดิม หลังผู้ใช้ตรวจเทียบข้อความและยืนยันแล้ว บันทึกผลแยกใน `p04-verified.json` และ `p04-verified.csv` เป็น `status=ok`, `manual_match=true` พร้อมข้อความยืนยัน เวลา UTC และ SHA-256 ของข้อความ

เก็บข้อความ 1,826 อักขระและ URL ที่อยู่ในข้อความไว้ใน `p04-reference.json` สำหรับตรวจรอบถัดไป การยืนยันนี้ใช้กับข้อความครั้งนี้ ไม่ถือว่าการดึงใหม่ผ่านอัตโนมัติ และไม่ได้ยืนยันว่าเว็บไซต์ปลายทางของลิงก์ทุกแห่งเข้าถึงได้

ภาพหลักฐานมีรูปและข้อความหลังกล่องชวนล็อกอิน ตัวทดลองไม่ได้ล็อกอิน ปิดกล่อง หรือดึงคำจากรูปด้วย OCR
