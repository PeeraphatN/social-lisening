## เหตุผลที่ต้องใช้ลิงก์เจาะจงโพสต์

รอบ `p05-browser-01` ใช้ลิงก์กลุ่มตามที่ผู้ใช้ส่งมา แม้หน้าแสดงโพสต์เป้าหมาย แต่ metadata description เป็นคำอธิบายกลุ่ม ตัวอ่านจึงได้ `preview_only` และไม่มีข้อความโพสต์ที่ตรงกับคำขึ้นต้นของ metadata ห้ามนำคำอธิบายกลุ่มไปใช้เป็นข้อความโพสต์

ใช้ group ID และ post ID ที่ผู้ใช้ระบุอยู่แล้วในลิงก์ เพื่อสร้าง URL ของโพสต์เดียวกัน แล้วตรวจในรอบ `p05-browser-02` โดยไม่ล็อกอิน ไม่ปิดกล่องชวนล็อกอิน และไม่หลบข้อจำกัดการเข้าถึง ได้ข้อความที่ตรงกับ DOM จำนวน 392 อักขระ

ทั้งสองรอบเป็นการตรวจลิงก์เดียวกันในรูปแบบต่างกัน ไม่ใช่การทดสอบรันซ้ำครบ 3 รอบของชุดทดลอง

ชื่อจาก `og:title` ในหน้านี้ประกอบด้วยชื่อกลุ่มและส่วนต้นของข้อความ ไม่ใช่ชื่อผู้เขียน จึงเก็บชื่อผู้โพสต์ที่ผู้ช่วยตรวจจากภาพใน `publisher` พร้อม `publisher_source=manual_browser_screenshot` และเก็บ metadata แยกไว้ ไม่อ้างว่าดึงชื่อผู้โพสต์อัตโนมัติผ่านแล้ว

ผลดิบคง `status=candidate_text_unverified`, `manual_match=null` ตามเดิม หลังผู้ใช้ยืนยันแล้ว บันทึกผลแยกใน `p05-verified.json` และ `p05-verified.csv` เป็น `status=ok`, `manual_match=true` พร้อมข้อความยืนยัน เวลา UTC และ SHA-256 ของข้อความ 392 อักขระ

เก็บ `p05-reference.json` เป็นข้อมูลอ้างอิง และรวมข้อมูลอ้างอิง P01–P05 ใน `references.json` โดยตรวจ hash ของข้อความทุกตัวอย่างก่อนใช้รันซ้ำ การยืนยันใช้กับข้อความที่ผู้ใช้ตรวจแล้ว ไม่ทำให้ผลดึงใหม่ผ่านโดยอัตโนมัติ

## ไฟล์ผลลัพธ์

อยู่ใน `experiments/facebook_posts/runs/`:

- `p05-post.txt`: ข้อความสำหรับตรวจ
- `p05-verified.csv`, `p05-verified.json` และ `p05-reference.json`: ผลที่ตรวจผ่านและข้อมูลอ้างอิง
- `p05-post.csv` และ `p05-post.json`: ข้อความ กลุ่ม ผู้โพสต์ และ URL ทั้งสองรูปแบบ
- `p05-browser-01.png` และ `p05-browser-02.png`: ภาพหลักฐาน
- `p05-browser-01-inspection.json` และ `p05-browser-02-inspection.json`: ผลตรวจแต่ละรูปแบบลิงก์

CSV เป็น UTF-8 with BOM ตรวจเปิดกลับได้หนึ่งรายการ ข้อความและ post ID ตรงกับ JSON เก็บเฉพาะข้อความของโพสต์เป้าหมายในไฟล์ส่งออก ไม่รวมคำอธิบายกลุ่มหรือความคิดเห็น

## ข้อจำกัดและขั้นต่อไป

ตัวดึงยังไม่ได้แปลง URL กลุ่มที่มี `multi_permalinks` ให้อัตโนมัติ การแปลงรอบนี้ใช้ ID ที่มีอยู่ในลิงก์ผู้ใช้ ไม่ได้ค้นหาโพสต์อื่นในกลุ่ม ไม่สรุปจากผลนี้ว่าสามารถเก็บทุกโพสต์หรือกลุ่มที่ไม่สาธารณะได้

ชุด P01–P05 รันครบ 3 รอบแล้ว เว้นอย่างน้อย 10 นาที ทุกครั้งตรงกับข้อมูลอ้างอิง ดู [รายงานผล](facebook-post-repeat-results.md) สำหรับข้อสรุปและข้อจำกัด
