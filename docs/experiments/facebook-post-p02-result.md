# ผลทดลอง P02: ข้อความยาวประกอบรูป

วันที่ทดลอง: 7 ตุลาคม 2026

ลิงก์จากผู้ใช้: https://www.facebook.com/photo/?fbid=1649985453249994&set=a.194492012132686

สถานะ: **P02 ผ่านการตรวจเทียบโดยผู้ใช้** ผู้ใช้ยืนยันว่า “ถูกต้องครับ” เมื่อ 7 ตุลาคม 2026 ตามเวลาไทย ตอนนี้ยืนยันแล้ว 2 จาก 5 โพสต์ ยังไม่ได้รันชุดทดลองครบ 3 รอบ

## ผลที่พบ

| รายการ | ผล |
| --- | --- |
| วิธี | Playwright/Chromium แบบไม่ล็อกอิน ไม่มีค่า API หรือบริการ scraping |
| HTTP | 200 |
| รูปแบบ | หน้าแสดงรูป `photo/?fbid=...` มีข้อความประกอบรูปยาวและปุ่ม “ดูเพิ่มเติม” |
| ข้อความ | พบข้อความที่ตรงกับคำขึ้นต้นใน embedded JSON เพียงหนึ่งรายการ ความยาว 3,438 อักขระ |
| ผู้เผยแพร่ | หน้าและภาพหน้าจอแสดงชื่อ SCIWAYS; metadata `og:title` ไม่มีชื่อผู้เผยแพร่ |

ข้อความเกี่ยวกับคำถามเรื่องกำเนิดจักรวาล ใช้เป็นตัวควบคุมทางเทคนิค ไม่ใช่ข้อมูลความคิดเห็นเกี่ยวกับ TKC

## ความครบถ้วนและข้อจำกัด

ภาพหน้าจอแสดงข้อความด้านขวาของรูปถูกย่อและมีปุ่ม “ดูเพิ่มเติม” รวมถึงกล่องชวนล็อกอิน ตัวทดลองไม่ได้ล็อกอิน ไม่ปิดกล่อง และไม่คลิกปุ่มขยาย ข้อความยาวถูกอ่านจากข้อมูลที่หน้าเว็บส่งมาให้เบราว์เซอร์

selector DOM ที่ใช้กับ P01 คือ `data-ad-rendering-role=story_message` ไม่พบในหน้านี้ (`dom_message_count=0`) แต่ตัวอ่าน embedded JSON ยังพบข้อความที่ตรงกับ metadata preview หนึ่งรายการ ข้อความที่ส่งออกยาวกว่า preview 156 อักขระ และจบด้วยชุด hashtags ของโพสต์

ตอนดึงคง `status=candidate_text_unverified`, `manual_match=null` ไว้ในผลดิบตามเดิม หลังผู้ใช้เทียบต้นฉบับและยืนยันความถูกต้องแล้ว บันทึกผลแยกใน `p02-verified.json` และ `p02-verified.csv` เป็น `status=ok`, `manual_match=true` พร้อมข้อความยืนยัน เวลา UTC และ SHA-256 ของข้อความที่ตรวจ

เก็บข้อความ 3,438 อักขระใน `p02-reference.json` เป็นข้อมูลอ้างอิงสำหรับรอบถัดไป การตรวจผ่านนี้ใช้กับข้อความครั้งนี้เท่านั้น ไม่ถือว่าการดึงครั้งใหม่ผ่านอัตโนมัติ ชื่อผู้เผยแพร่ยังเป็นค่าที่ตรวจจากภาพ ไม่ใช่ความสามารถดึงชื่ออัตโนมัติที่ผ่านแล้ว

ชื่อ SCIWAYS ในไฟล์ส่งออกเป็นค่าที่ตรวจจากภาพหน้าจอโดยผู้ช่วย ระบุ `publisher_source=manual_browser_screenshot` ไม่อ้างว่าตัวดึง metadata หาได้อัตโนมัติ

เวลาบนหน้าแสดงประมาณ 1 ชั่วโมงที่แล้ว เก็บข้อความเวลาดิบตามจริง และคง `published_at=null` เพราะยังไม่ยืนยันเวลาตีพิมพ์แน่นอน

## ไฟล์ผลลัพธ์

อยู่ใน `experiments/facebook_posts/runs/`:

- `p02-post.txt`: ข้อความสำหรับผู้ใช้ตรวจเทียบ
- `p02-verified.csv`, `p02-verified.json` และ `p02-reference.json`: ผลที่ตรวจผ่านและข้อมูลอ้างอิง
- `p02-post.csv` และ `p02-post.json`: ข้อความและข้อมูลต้นทาง
- `p02-browser-01.png`: ภาพหลักฐาน
- `p02-browser-01-inspection.json`: ข้อมูลตรวจจากเบราว์เซอร์

ตรวจ CSV แบบ UTF-8 with BOM แล้ว เปิดกลับมาได้หนึ่งรายการ และข้อความตรงกับ JSON ไม่มีการดึงคำในรูปด้วย OCR ข้อมูลความคิดเห็นที่เห็นในหน้าจอไม่ได้รวมในไฟล์โพสต์ที่ส่งออก
